## 🚀 How to Run

### Quick Start
```bash
# Terminal 1 - Backend
cd backend
npm install
npm run dev

# Terminal 2 - Frontend
cd frontend
npm install
npm start
```

### Or use the batch file (Windows)
```bash
# Just double-click:
start.bat
```
